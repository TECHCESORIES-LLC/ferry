How to save ChatGPT and Claude chats to Notion

Updated November 24, 2026

Notion is where many people keep research and project notes, so it's a natural place for useful AI conversations. Pasting a long chat into Notion often turns code into plain text and tables into a mess. This guide shows the manual method, how to set up a Notion integration, and how Ferry Pro sends chats in as real Notion blocks.

Why keep AI chats in Notion at all?

Chat history inside ChatGPT or Claude is hard to search, can't be linked from your other work, and disappears if you delete a chat or close the account. In Notion, a useful answer sits next to the project it was for: you can link it from a spec, share it with a teammate who doesn't use the same assistant, and find it again with Notion's search.

Method 1: Copy and paste

  1. In ChatGPT or Claude, use the copy button under a reply. Both copy the reply as Markdown.
  2. In Notion, paste into a page. Notion converts much of the Markdown into blocks as you paste.
  3. Check code blocks and set their language by hand, and fix any table that came through as text.

This is fine for one answer. For a whole conversation you have to copy every message one by one, and add your own prompts back in so the page still makes sense.

Method 2: Export to Markdown, then import

Notion can import .md files (Settings, then Import, then Text & Markdown). That gives you a clean page per chat:

  1. Save the chat as Markdown. Ferry does this free in one click, or see our ChatGPT to Markdown guide for the manual way.
  2. In Notion, open Settings, then Import, and choose Text & Markdown.
  3. Select the .md file. Notion creates a new page from it.

It works, but it's two tools and several clicks per chat, and imported pages land wherever Notion puts them, so you move them afterwards.

Method 3: Ferry Pro, direct to a Notion page

Ferry Pro talks to Notion's API from your browser, using a key you create. Set it up once:

  1. Go to notion.so/my-integrations and create a new internal integration for your workspace. Copy its secret.
  2. Open the Notion page where chats should go. In the … menu, choose Connections and add your integration, so it can write to that page.
  3. In Ferry's settings, paste the secret and choose the destination page.

After that, open any ChatGPT or Claude chat, click Ferry, and choose Notion. Ferry builds the page from proper Notion blocks:

Heading 2   You
Paragraph   Write a memoized Fibonacci in Python...
Heading 2   ChatGPT
Paragraph   Here is a version using lru_cache:
Code        (language: python)
            @lru_cache
            def fib(n): ...
Bulleted    each list item stays a list item
Quote       quotes stay quotes

Your Notion key is stored in your browser and only sent to api.notion.com. The chat goes from your browser straight to Notion. Ferry's own server is never on that route.

Tips for a tidy AI-chat database

  • Give chats one home. Send every chat to the same parent page, so they collect in one place instead of scattering across your workspace.
  • Rename on arrival. AI-generated titles are vague. A clear title makes Notion search far more useful.
  • Keep the integration narrow. Connect it only to the page Ferry writes to. Notion integrations can only see pages you share with them.

Troubleshooting

  • "Could not find page" or a 404 from Notion. The integration isn't connected to that page. Open the page, use … and Connections, and add your integration.
  • "Unauthorized" or a 401. The secret was copied wrong or the integration was deleted. Copy the secret again from notion.so/my-integrations.
  • Very long chats. Notion limits how much text goes in each block and how many blocks go in each request. Ferry splits long chats to fit, so a huge chat simply takes a moment longer.

Common questions

Is Notion export free in Ferry?

Direct Notion export is a Pro feature. Saving the chat as Markdown is free, and Notion can import that file (Settings, Import, Text & Markdown).

Does Ferry see my Notion workspace?

Ferry uses the integration key you create, and Notion integrations can only reach pages you explicitly connect them to.

Where is my Notion key stored?

In your browser, on your device. It is only sent to api.notion.com when you export.

Do code blocks keep their language in Notion?

Yes. Ferry creates Notion code blocks with the language set from the chat.

Does it work with Claude too?

Yes. Notion export works from ChatGPT and Claude chats.
