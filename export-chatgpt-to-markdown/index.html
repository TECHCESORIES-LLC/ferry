How to export ChatGPT conversations to Markdown

Updated November 24, 2026

There are two ways to get ChatGPT conversations out as Markdown. OpenAI's built-in export gives you your whole account as a ZIP of JSON files. A browser extension like Ferry turns the one chat you are reading into a clean .md file in a click. This guide covers both, step by step, so you can pick the one that fits.

Method 1: ChatGPT's built-in data export

This is the official route, and it is the right one when you want a full backup of everything in your account.

  1. Open ChatGPT on the web and click your name or profile picture in the corner.
  2. Go to Settings, then Data controls.
  3. Click Export data, then Confirm export.
  4. Wait for the email (or SMS, for phone-only accounts). OpenAI says exports can take up to 7 days, though most arrive much sooner.
  5. Click Download data export. The link expires 24 hours after you receive it, so download it straight away.
  6. Unzip the file. Your chats are in conversations.json, or split across numbered files like conversations-000.json for large accounts. There is also an HTML viewer for browsing.

What you actually get

The export is built for archiving, not for reading or reusing. Every conversation is a tree of message nodes keyed by ID, with metadata on every node. A single short exchange looks roughly like this:

{
  "title": "Memoized Fibonacci",
  "mapping": {
    "a1b2...": {
      "message": {
        "author": { "role": "user" },
        "content": { "content_type": "text",
                     "parts": ["Write a memoized Fibonacci..."] }
      },
      "parent": "9f8e...",
      "children": ["c3d4..."]
    }
  }
}

To turn that into Markdown yourself, you need a script that walks each conversation's mapping from the root, follows the active branch, and writes each message out with a role heading. Here is a minimal version in Python:

import json, pathlib, re

data = json.load(open("conversations.json"))
out = pathlib.Path("chatgpt-md"); out.mkdir(exist_ok=True)

for convo in data:
    nodes = convo["mapping"]
    node = convo["current_node"]          # newest message on the active branch
    chain = []
    while node:
        msg = nodes[node].get("message")
        if msg and msg["content"].get("parts"):
            text = "\n".join(p for p in msg["content"]["parts"] if isinstance(p, str))
            if text.strip():
                chain.append((msg["author"]["role"], text))
        node = nodes[node].get("parent")
    chain.reverse()
    name = re.sub(r"[^\w -]", "", convo.get("title") or "untitled")[:80]
    with open(out / f"{name}.md", "w") as f:
        f.write(f"# {convo.get('title')}\n\n")
        for role, text in chain:
            f.write(f"## {role}\n\n{text}\n\n")

That works for plain text. It gets harder from there: the JSON holds the model's raw text, so you also have to deal with system and tool messages, uploaded files, images, canvases and branches you edited.

Pros and cons of the official export

  • Good: complete, official, free, and it includes every conversation you haven't deleted.
  • Slow: you wait for an email, and you have to download within 24 hours.
  • All or nothing: you can't export one chat. You get the whole account every time.
  • Not Markdown: you need a script, or a tool that understands the format, before you can paste anything into notes or a repo.

Method 2: Ferry, one chat to Markdown in a click

When you want the conversation in front of you as a file, now, Ferry is faster. It reads the chat from the page in your browser and converts it there.

  1. Install Ferry from the Chrome Web Store. It also works in Edge, Brave and Arc.
  2. Open the ChatGPT conversation you want to keep.
  3. Click the Ferry icon in the toolbar. Ferry reads that chat only at this moment.
  4. Pick an output: download .md, .json or PDF, copy Markdown to the clipboard, or send it to Obsidian.

Here is what Ferry writes for a short coding chat. The code fence keeps its language, the math stays as LaTeX, and the table is a real Markdown table:

---
title: Memoized Fibonacci
source: ChatGPT
---

## You
Write a memoized Fibonacci in Python and show the first values in a table.

## ChatGPT
Here is a version using **lru_cache**:

```python
from functools import lru_cache

@lru_cache
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
```

It grows like $\varphi^n/\sqrt{5}$.

| n  | fib(n) |
|----|--------|
| 10 | 55     |
| 20 | 6765   |

Every file starts with a small front matter block (title and source), so it drops straight into Obsidian, a static site or a docs repo.

Common questions

Does ChatGPT have a built-in "export to Markdown" button?

No. ChatGPT can share a chat as a link or export your whole account as JSON, but it has no option to save a single conversation as a Markdown file. Copying the page works for short replies but usually breaks code blocks and tables.

How long does the official ChatGPT export take?

OpenAI says it can take up to 7 days to arrive. The download link expires 24 hours after you receive it.

Does Ferry upload my conversation anywhere?

No. The conversion runs in your browser and the file is saved on your computer. Ferry reads the chat when you click it, or as you browse if you turn on Pro auto-capture.

Can I export all my ChatGPT chats at once with Ferry?

Yes, with Pro. It reads your conversation list from your logged-in session and packs every chat into one ZIP of Markdown files.

Will code blocks keep their language?

Yes. Fenced code blocks keep their language tag (for example ```python), so syntax highlighting works in Obsidian, GitHub and most editors.
