How to export Claude chats to Obsidian

Updated November 24, 2026

Obsidian is just a folder of Markdown files, which makes it a great home for Claude conversations you want to keep. The hard part is getting them out of Claude in a format Obsidian can use. Here are the manual routes and the one-click route, with what each one costs you in time.

Method 1: Copy and paste (fine for short chats)

  1. Open the conversation on claude.ai.
  2. Hover over a reply and click the copy icon. Claude copies that reply as Markdown.
  3. Paste it into a new Obsidian note. Repeat for every message you want, and type your own prompts back in by hand.

This keeps the formatting of each reply, but you lose the back-and-forth structure unless you rebuild it, and it gets tedious past a few messages. Artifacts, such as a document or a piece of code Claude made in the side panel, have to be copied separately.

Method 2: Claude's data export

For a full archive, Claude has an official export:

  1. On claude.ai or Claude Desktop, click your initials in the lower left.
  2. Open Settings, then Privacy.
  3. Click Export data. You can't start an export from the iOS or Android apps.
  4. Download the file from the email. The link expires 24 hours after it is created and may only work once.

The download is JSON. Each conversation holds a list of messages with a sender and text, which you would need to convert into one Markdown file per chat. A short Python script can do it:

import json, pathlib, re

convos = json.load(open("conversations.json"))
vault = pathlib.Path("~/Obsidian/AI chats").expanduser()
vault.mkdir(parents=True, exist_ok=True)

for c in convos:
    name = re.sub(r"[^\w -]", "", c.get("name") or "Untitled")[:80]
    lines = ["---", f"title: {c.get('name')}", "source: Claude",
             f"created: {c.get('created_at', '')[:10]}", "---", ""]
    for m in c.get("chat_messages", []):
        who = "You" if m.get("sender") == "human" else "Claude"
        lines += [f"## {who}", "", m.get("text", ""), ""]
    (vault / f"{name}.md").write_text("\n".join(lines))

Two caveats. Field names in exports can change between versions, so check your file first. And the export doesn't include the original files you uploaded to Claude.

Method 3: Ferry, straight into your vault

  1. Install Ferry from the Chrome Web Store (Chrome, Edge, Brave or Arc).
  2. In Ferry's settings, enter the name of your Obsidian vault. You only do this once.
  3. Open the Claude chat and click the Ferry icon.
  4. Choose Obsidian. Obsidian opens with a new note holding the whole conversation.

The note gets front matter that Obsidian shows as Properties, so you can sort and search by source and title:

---
title: Postgres index tuning
source: Claude
---

## You
Why is this query doing a sequential scan?

## Claude
The planner skips the index because...

Nothing goes through a Ferry server on the way. Ferry builds the note in your browser and hands it to the Obsidian app on your computer.

Organizing Claude chats in Obsidian

  • One folder for AI chats. Keep exports in something like AI chats/Claude, so they don't mix with notes you wrote yourself.
  • Use the properties. The source property lets a Dataview query or a Bases view list every Claude chat, or compare them with ChatGPT chats.
  • Link from your own notes. A link like [[Postgres index tuning]] from a project note turns a chat into reference material instead of a dead log.
  • Trim before you file. Delete the dead ends. A chat note is more useful when it holds only the answer you used.

Troubleshooting

  • Obsidian opens, but in the wrong vault. The vault name in Ferry's settings must match the vault's folder name exactly, including capital letters.
  • The export email never arrives. Check spam, and make sure you're signed in to the same account on claude.ai when you open the link.
  • Odd characters in file names. Obsidian doesn't allow some characters, such as : or /, in note names. Rename the note, or strip them in your script as the example above does.

Common questions

Does Claude have a built-in Obsidian export?

No. Claude can copy single replies as Markdown and export your whole account as JSON, but it has no direct export to Obsidian.

Do I need an Obsidian plugin for Ferry?

No. Ferry uses the standard way Obsidian accepts new notes from other apps. You only set your vault name once.

Do Claude artifacts come along?

Code blocks in the chat are kept as fenced code. With Pro, code can also be saved as separate files next to the Markdown.

Can I move my whole Claude history into Obsidian?

Yes. Ferry Pro exports every Claude chat as Markdown files in one ZIP, which you can unzip straight into your vault folder.

Is my conversation sent to Ferry?

No. Ferry converts the chat in your browser and passes it to Obsidian on your computer.
