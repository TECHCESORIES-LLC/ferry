How to export Gemini chats to Markdown

Updated November 24, 2026

Gemini makes it easy to bring chats in: it can import your ChatGPT and Claude history. Getting your own Gemini conversations out in a usable form is harder. Here is Google's official route through Takeout, where it falls short, and how to save a Gemini chat as Markdown in one click instead.

Method 1: Google Takeout

Google Takeout is the official way to download your Gemini chats in bulk. There's one catch that trips up most people: your conversations are not under the item called "Gemini". That item only holds your Gems. Chats live under My Activity.

  1. Go to takeout.google.com, signed in with the account you use for Gemini.
  2. Under Select data to include, click Deselect all.
  3. Scroll to My Activity and tick it.
  4. Click All activity data included, then Deselect all in the pop-up, tick only Gemini Apps, and click OK.
  5. Optional but useful: click Multiple formats and change Activity records from HTML to JSON.
  6. Click Next step, pick ZIP and a delivery method, then Create export. Google emails you when it's ready.

What you get, and why it's painful

Takeout gives you an activity log, not a set of conversations. Each prompt and response is an entry in one long MyActivity.html or MyActivity.json, ordered by time. A JSON entry looks roughly like this:

{
  "header": "Gemini Apps",
  "title": "Prompted Write a memoized Fibonacci in Python",
  "time": "2026-11-20T18:42:07.311Z",
  "safeHtmlItem": [{ "html": "<p>Here is a version using...</p>" }]
}
  • No conversation threads. Prompts from different chats are interleaved by time, so you have to piece each conversation back together.
  • Responses are HTML, not Markdown. Code blocks and tables need converting before they're useful in notes.
  • It's slow. Exports can take hours or longer, and you request the whole archive every time.
  • It only covers saved activity. Chats from while Gemini Apps Activity was off, temporary chats and deleted chats are not included.
  • It's not portable. ChatGPT and Claude can't import this file, so it's a backup, not a way to move.

If you only need the content of the entries, a short script turns the JSON into one Markdown file per day:

import json, collections, html, re

items = json.load(open("MyActivity.json"))
by_day = collections.defaultdict(list)
for it in items:
    prompt = it.get("title", "").removeprefix("Prompted ")
    reply = " ".join(h["html"] for h in it.get("safeHtmlItem", []))
    reply = html.unescape(re.sub(r"<[^>]+>", "", reply))   # crude: drops formatting
    by_day[it["time"][:10]].append(f"## You\n{prompt}\n\n## Gemini\n{reply}\n")

for day, entries in sorted(by_day.items()):
    open(f"gemini-{day}.md", "w").write("\n".join(reversed(entries)))

Note the comment: stripping the HTML loses code blocks and tables. Doing it properly means writing a real HTML-to-Markdown converter.

Method 2: Gemini's Export to Docs

For a single response, Gemini's Share & export menu can send it to Google Docs. That's handy for prose, but it covers one response at a time, and you end up with a Google Doc, not a Markdown file.

Method 3: Ferry, the open Gemini chat to Markdown

Ferry 0.10.0 adds Gemini, free. Gemini access is opt-in, so Ferry asks for it only if you use it. With Pro you can also export every Gemini chat into one ZIP.

  1. Install Ferry from the Chrome Web Store. It also works in Edge, Brave and Arc.
  2. Open a chat on gemini.google.com and click the Ferry icon.
  3. The first time, click Allow Gemini. Chrome asks you to approve access to gemini.google.com. You can remove it at any time in Chrome's extension settings.
  4. Pick an output: download .md, copy to the clipboard, or send it to Obsidian.

You get the whole thread, in order, as one file:

---
title: Memoized Fibonacci
source: Gemini
---

## You
Write a memoized Fibonacci in Python.

## Gemini
```python
from functools import lru_cache

@lru_cache
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
```

Ferry reads the chat only when you click it, converts it in your browser, and saves the file on your computer.

Common questions

Why is my Gemini Takeout export empty?

Most often because only "Gemini" was ticked, which exports Gems, not chats. Select My Activity and filter it to Gemini Apps instead. Also check you used the same Google account as Gemini, and that Gemini Apps Activity was on.

Can Gemini export my chats to ChatGPT or Claude?

Not directly. Gemini can import chats from ChatGPT and Claude, but its own Takeout export is an activity log that those tools can't import. A Markdown file is the most portable format to carry a chat between assistants.

Why does Ferry ask for Gemini permission separately?

Gemini support is optional. Ferry only gets access to gemini.google.com after you click Allow Gemini and approve it in Chrome, and you can revoke it at any time.

Does Ferry export my whole Gemini history at once?

Yes, with Ferry Pro. It exports every Gemini chat as a Markdown file into one ZIP, already split into conversations, unlike Takeout. Exporting the chat you have open is free.

Is my Gemini chat sent to Ferry?

No. Ferry converts the chat in your browser and saves the file on your device.
